# Portfolio Signal Dashboard

## Always-on private cloud mode

Set `DASHBOARD_RUNTIME_MODE=cloud` to serve a persistent last-known-good snapshot while refreshes run in the background. The production deployment uses systemd, `/var/lib/portfolio-dashboard` for snapshot/tracker data, `/etc/portfolio-dashboard.env` for secrets, and Tailscale Serve with the app bound to `127.0.0.1`.

Installation, update, backup, rollback, and private phone access are documented in [`deploy/cloud/README.md`](deploy/cloud/README.md).

국내 보유종목 38개를 기준으로 매일 추가매수, 분할매수, 물타기 금지, 익절/축소, 관망 신호를 보여주는 로컬 대시보드입니다.

## 화면 역할

- `종목 탐색`: KOSPI와 KOSDAQ을 한 번에 계산한 뒤, 한 화면에서 시장별 독립 순위를 표시합니다.
- `반등후보`: 기본 보기입니다. 매수보류·고위험·하락 중 종목을 뒤로 보내고, 하락정지 상태 안에서 Leader, 조정폭, Stabilize, Risk, 거래강도·수급 순으로 정렬합니다.
- `타이밍`: 기존 Main 70점 + Scout 30점을 유지한 현재 진입 타이밍 비교입니다.
- `주도주`: 장기 가격·추세 품질을 A/B/C/D로 확인합니다. 타이밍 점수에는 다시 가산하지 않습니다.
- `CAFE`, `MTT`: 기존 전략 정의를 통과한 종목만 동일한 표에서 필터링합니다.
- `시뮬레이터`: 신규 가상 진입부터 Leader·반등·CAFE·MTT 메타데이터를 함께 기록합니다.
- `Ranking V2 실전검증`: 실제 주문 없이 당시 순위 snapshot과 이후 3·5·10거래일 성과를 누적 검증합니다.

새로고침 한 번으로 두 시장을 함께 계산해 30분 공용 캐시에 저장합니다. 시장 탭, 보기 모드, 컬럼 정렬은 메모리의 같은 행을 사용하므로 KIS 전체 계산을 다시 호출하지 않습니다. 첫 전체 계산은 KIS 호출 제한 때문에 수 분 걸릴 수 있습니다.

## 한국투자 Open API 키

`.env`에 아래 값을 넣으면 서버가 한국투자 Open API를 호출합니다. 키는 브라우저로 내려가지 않습니다.

```env
KIS_APP_KEY=...
KIS_APP_SECRET=...
```

정확한 보유수량, 평균단가, 평가손익까지 실제 계좌와 맞추려면 계좌번호도 넣습니다.

```env
KIS_ACCOUNT_NO=12345678-01
```

또는 아래처럼 나눠서 넣어도 됩니다.

```env
KIS_CANO=12345678
KIS_ACNT_PRDT_CD=01
```

계좌번호가 없으면 현재가만 KIS에서 가져오고, 보유수량/평균단가는 스크린샷에서 만든 `portfolio.js` 기준으로 계산합니다. 이 경우 실제 계좌 손익과 차이가 날 수 있습니다.

## 신호 기준

- `수급점수`: 외국인·기관·프로그램 순매수, 수급강도, 체결강도, RSI, 거래대금 회전, R2 여유를 종합한 0~100점 점수입니다.
- `추가매수`: 수급점수 75점 이상, 수급우호 2/3 이상, 비중 여유, RSI/가격 위치 과열 아님.
- `분할매수 가능`: 손실 구간이지만 수급점수 50점 이상, 수급강도 0.35% 이상, 외국인+기관 합산 순매수 양수, 비중 8% 이하.
- `물타기 금지`: 손실 구간인데 수급점수 또는 수급우호가 부족하거나 프로그램/외국인/기관 흐름이 약함.
- `익절/축소`: 수익 구간이 크고 비중이 높거나, R2 여유 부족/과열/수급 약화가 겹침.
- `비중축소`: 수익은 있지만 단일 종목 비중이 커졌고 수급점수가 추가 확대를 정당화하지 못함.
- `손절 검토`: 손실이 크고 외국인·기관·프로그램 수급이 동시에 약하거나 하락 추세가 겹침.

### 방어/패닉 모드

포트폴리오 전체가 무너지는 날에는 매수 신호를 자동으로 잠급니다.

- `방어`: 평균 등락률 -3% 이하, 하락 종목 65% 이상, 또는 -5% 이상 급락 종목 30% 이상
- `패닉`: 평균 등락률 -5% 이하, 하락 종목 80% 이상, 또는 -5% 이상 급락 종목 45% 이상
- 방어/패닉 모드에서는 일반 `분할매수 가능`이 거의 꺼지고, 손실 종목은 기본적으로 `물타기 금지` 또는 `방어 관망`으로 이동합니다.
- 예외적으로 수급점수 85점 이상, 외국인·기관·프로그램 우호 2개 이상, 연속 수급, 프로그램 비매도, 낙주반등 확인이 같이 있어야 분할매수 검토가 가능합니다.
- 패닉 모드에서 손실 -18% 이하이면서 당일 -7% 이상 급락하거나 수급이 약하면 `손절 검토`로 올립니다.

### 수급 참고 데이터

- KIS 현재가, 일봉, 체결강도, 투자자 추정, 종목별 일별 투자자, 프로그램 매매를 사용합니다.
- judal.co.kr 외국인/연기금 연속순매수 페이지는 연속 일수 보정용으로만 사용합니다.
- KIS 일부 호출이 실패하면 해당 항목만 기본값으로 보정하고, 가격/손익은 가능한 실시간 값을 유지합니다.
- KIS 초당 호출 제한을 피하기 위해 요청 간격을 둡니다. 첫 정밀 로딩은 30초 안팎 걸릴 수 있고, 이후에는 캐시로 빨라집니다.

## 유통시총/거래강도

핵심 4개 지표를 별도 `거래강도` 점수로 계산합니다.

- `거래대금 ÷ 유통시총`: 유동주식비율이 있으면 최우선 사용, 없으면 `거래대금 ÷ 시총`으로 대체
- `오늘 거래대금 ÷ 20일 평균 거래대금`: 평소 대비 돈이 몇 배 붙었는지
- `외인+기관 순매수 ÷ 유통시총`: 큰손 순매수가 종목 몸집 대비 의미 있는지
- `외인+기관 순매수 ÷ 당일 거래대금`: 오늘 거래를 큰손이 주도했는지

유동주식비율을 직접 보정하려면 `free-float.example.json`을 복사해 `free-float.json`을 만들고 종목코드별 비율을 넣습니다.

```json
{
  "094170": 42.5,
  "035420": 82.0
}
```

값은 `42.5`처럼 퍼센트로 넣어도 되고, `0.425`처럼 소수로 넣어도 됩니다.

## 낙주반등 체크

`README_낙주반등_백테스트.md`의 confirmed 전략을 현재가 기반으로 간이 적용합니다.

- 낙폭: 전일 종가 대비 `-5% 이하`, `-12% 미만 급락은 제외/복기`
- 장중 진입 시간: `09:30~14:30`
- 반등 확인: 당일 저점 대비 `+1.2% 이상`
- 양봉 전환: 현재가가 당일 시가 이상
- VWAP 회복: 현재가가 누적 거래대금/거래량 기준 VWAP 이상
- 수급 확인: 수급점수 50점 이상 또는 외국인/기관/프로그램 우호 2개 이상
- 거래대금: 당일 누적 거래대금 30억 이상
- 장마감 이후: 신규 진입이 아니라 `장마감 복기`로 표시

카드에 표시되는 검토가는 현재가 ±0.5%, 손절은 -5%, 익절은 +3%/+5%/+7% 기준입니다.

## Ranking V2 실전 추적

전체 KOSPI·KOSDAQ screener가 정상 완료되면 당시 Ranking V2 결과를 `data/ranking-live-history.jsonl`에 저장합니다. 이 파일과 집계 캐시 `data/ranking-live-summary.json`은 개인 실시간 기록이므로 Git에서 제외됩니다.

- 중복 방지 키: `signalDate + market + ticker`
- 진입 기준: 신호일 장마감 확인 후 다음 거래일 시가
- 평가 기준: 진입 후 3·5·10거래일 종가
- 비용: historical V2.1과 동일한 왕복 0.23%
- MFE/MAE: 진입일부터 각 평가일까지의 일봉 고가·저가 기준
- 시장내 초과: 동일 신호일·동일 시장 추적 universe의 평균 순수익 대비

기록 당시 순위와 Tier, Leader, Scout, Risk, Stabilize, CAFE/MTT 값은 미래 결과를 채울 때 변경하지 않습니다. 대시보드가 실행되지 않았던 거래일의 Ranking을 현재 데이터로 사후 생성하지도 않습니다.

실전검증 화면은 `http://localhost:5177/ranking-validation.html`에서 확인합니다.
