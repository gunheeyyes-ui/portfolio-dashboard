# 107전략 OOS → 독립 가상계좌 연구실

- URL: `/strategy-paper-lab.html`
- API: `GET /api/strategy-paper-lab` (기존 대시보드 Basic Auth)
- 시작: **2026-10-12 신호일**부터 forward-only. 과거 신호/가상손익 소급 없음.
- 대상: Node OOS 등록 전략 전부, 현재 107개 (기본 94 + 합의 13).
- 비교: 전략별 독립 가상계좌, 청산 3·5·10·20거래일. 현재 428개.
- 가상 규칙: 기존 paper-auto 모델 재사용, 초기 원금 1억원, 종목당 1천만원 한도, 최대 10종목, 다음 거래일 시가, 정수주, 중복진입 제한, 비용 0.23%와 유동성별 추가 슬리피지.
- 기존 `/api/paper-auto`, Simulation V1/V2, 107개 OOS registry와 원본 history JSONL **변경 없음**.
- 새 가상계좌는 API GET 시 기존 불변 selection/record를 읽어 결과를 **파생 계산**. 새 거래 원장을 쓰지 않으며 실제 KIS 주문 기능 없음.

## 자동 선별 (통계적 확정이 아닌 잠정 관찰)

1. OOS 10거래일 관측을 코호트(날짜 × 시장)별 동등비중으로 재계산.
2. 저장된 시장상태의 사전차단과 이상 진입갭/가격 단절을 무결성 검사로 제외. 기존 OOS 원자료는 그대로 유지.
3. 무결성 비교 가능 10D 코호트 20개 이상, 평균 비용후 수익률 및 시장 대비 초과수익 모두 양(+)인 전략을 잠정 통과.
4. 명백한 대조군(FLAG_C, FLAG_I)은 선별에서 제외.
5. 상위 후보 목록에서는 최근 5개 신호일의 선택 종목 집합 Jaccard 유사도 0.85 이상을 대표 하나로 압축. 비슷한 전략도 독립 가상계좌 추적은 계속.
6. 단기목록 최대 8개. 선정 여부와 무관하게 **모든** 전략을 4개 보유기간으로 추적하여 사후 선택편향을 줄임.

주의: 20코호트는 시작을 위한 **연구 필터**이지 통계적 유의성, 독립적인 거래 20건 또는 수익의 재현성 인증이 아니다. 초기 데이터의 거래일 결손과 전략 중복이 존재한다. 자동 승격/실계좌 주문은 수행하지 않음.

## 평가 메타데이터

- `shortlist`: 연구 관찰 우선 후보.
- `leaderboard`: OOS 전 전략(관측 성과 정렬) + 각 보유기간 독립 가상계좌 성과.
- `oos`: 무결성 비교 가능한 10D 코호트 N/평균 순수익/시장초과수익.
- `rawOos`: 보존된 기존 OOS 원자료 (비교/검증용).
- `holds[N]`: 별도 초기자본 기반 누적 계좌수익·실현건수·PF·MDD·격리건수.
- `comparableReturnPct`: 이상가격에 따른 청산손익을 원래 결과에서 분리한 **진단 비교**. 투자 여력을 재배분한 가상시뮬레이션 아님.
