## 치명적 연구 제약
1. 백테스트 캐시는 2026년경 선택된 KOSPI/KOSDAQ 100종목씩 200종목이며, 2024년 당시의 시장 전체·상장폐지·상장진입 종목을 포함하지 못하므로 **심각한 생존자/종목선정 편향**.
2. 107개 전략 정의가 백테스트 기간 후에 만들어져 TRAIN/VALIDATION/HOLDOUT 시간 분할 자체가 진정한 OOS 성과를 보장하지 않음.
3. 4,494가지 정책×기간(13,482 측정)을 탐색했으므로 **다중비교·과최적화·상관 전략 중복** 가능성.
4. 과거 시장 관리종목/정지/체결 호가잔량/상한가 대기열 재현 불가, 추정 슬리피지만 적용.
5. 실제 2026-08-24 이후 OOS에는 심각한 수익률 이상가격(-99%대 사례)과 관측 누락이 있어, 원자료를 검증한 후에만 실전 전략 선정 가능.
6. 고수익 거래 상위 5건의 이익 제거는 사후 민감도 검사일 뿐 당시 실제 체결 순서를 재계산한 완전한 대체 포트폴리오가 아니다.

기존 전략 Registry, OOS 원장·산식, 20개 기존 Shadow Auto, 428개 신규 전진 가상계좌 **변경하지 않음**.
